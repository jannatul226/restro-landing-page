
# Restro - Restaurant Landing Page

A responsive-style Restro restaurant landing page built with only HTML and CSS. It features a dark themed hero section with a full-screen background image, an orange accent color, and a clean navigation bar.

## Features

- Full-screen hero section with a dark overlay on the background image
- Navigation bar with icons and a hover effect on each menu item
- Bold headline with a highlighted "Delicious" keyword
- Circular featured food image
- Styled "Book Table" call-to-action button
- Clean layout built with Flexbox

## Built With

- HTML5
- CSS3 (Flexbox, background overlay, hover effects)
- [Font Awesome 4.7](https://fontawesome.com/v4/) for icons
- [Google Fonts](https://fonts.google.com/) (Open Sans)

## How to Run

1. Clone the repository
   ```
   git clone https://github.com/jannatul226/restro-landing-page.git
   ```
2. Open the project folder
3. Double-click `index.html` to open it in your browser

An internet connection is needed to load the icons and fonts.
